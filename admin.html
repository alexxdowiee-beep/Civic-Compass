Edit the app's data and publish changes directly to GitHub.

Read this before using it. The passphrase below is a soft speed-bump, not real security — this is a static page and anyone who finds the URL can view its source. The actual protection is your GitHub token: without a valid token that has write access to your repo, nobody can save changes, no matter what passphrase they guess. Use a fine-grained GitHub token scoped to only this repo, with only "Contents: read and write" permission, and set an expiry date. Never share this page's URL together with your token. Your token is kept only in this browser tab's memory — it is never sent anywhere except directly to api.github.com from your own device.

This is just a personal reminder step — nothing is checked against a server.

Create one at github.com → Settings → Developer settings → Fine-grained tokens. Scope it to this one repo, "Contents: Read and write" only.
